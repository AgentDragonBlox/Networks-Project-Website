Traceroute

traceroute/traceroute.pypython -m traceroute

run_traceroute(target, max_hops=30, timeout=2, queries=3) runs tracert on Windows or traceroute elsewhere, then turns the text output into Hop objects inside a TracerouteResult. It never raises for network problems. Those come back as success and error.

The trick: Time To Live

How it works

validate_target()

Strict allow-list: letters, digits, . : -, at most 253 characters, and no leading -. A value like -w 0 x can't be smuggled in as an option.

build_command()

tracert -d -h N -w ms or traceroute -n -m N -q Q -w s. -d and -n skip reverse DNS, so the trace is faster and shows plain IPs.

Run with a budget

The overall timeout is max_hops × probes × timeout + 10 s. On timeout the partial output is kept. A missing binary returns an install hint.

parse_traceroute_output()

Only lines that start with a hop number are used. Each one is split into *, RTT and IP tokens, and annotations like !H are ignored.

Destination check

The destination IP comes from the header line. reached_destination is true only if a hop that responded has that address.

    View source: parse_traceroute_output()

    _HOP_LINE_RE = re.compile(r"^\s*(\d+)\s+(.*)$")
_TOKEN_RE = re.compile(
    r"(?P<star>\*)"
    r"|(?P<rtt><?\d+(?:\.\d+)?)\s*ms\b"
    r"|(?P<ipv4>\b(?:\d{1,3}\.){3}\d{1,3}\b)"
    r"|(?P<ipv6>(?<![\w:])[0-9a-fA-F]{0,4}(?::[0-9a-fA-F]{0,4}){2,7}(?![\w:]))"
)

for line in output.splitlines():
    match = _HOP_LINE_RE.match(line)
    if not match:
        continue
    hop = Hop(hop_number=int(match.group(1)))
    for token in _TOKEN_RE.finditer(match.group(2)):
        if token.group("star"):
            hop.rtts_ms.append(None)
        elif token.group("rtt"):
            hop.rtts_ms.append(_parse_rtt(token.group("rtt")))   # "<1" -> 1.0
        else:
            address = token.group("ipv4") or token.group("ipv6")
            if _is_valid_ip(address) and address not in hop.addresses:
                hop.addresses.append(address)
    hops.append(hop)
