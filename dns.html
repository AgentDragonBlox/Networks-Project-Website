DNS Resolution

dns/dns_lookup.pydnspython

resolve(target) turns a hostname into an IP address, or an IP back into a hostname. It always returns the same dictionary shape, so the caller never needs a try/except. Failures are reported through status and error.

How it works

Validate input

Rejects None, empty strings, names over 253 characters and names containing spaces before any query is sent.

Special-case localhost

localhost comes from the hosts file, not DNS, so the module answers 127.0.0.1 itself with TTL 0.

Reverse lookup for IPs

If ipaddress.ip_address() accepts the input, it builds x.x.x.x.in-addr.arpa and asks for a PTR. If that fails, the result is still a success.

Forward lookup

Queries A, AAAA and MX in that order, each with a 5 s lifetime. NoAnswer is skipped, NXDOMAIN stops at once, and other errors are remembered.

Collect & de-duplicate

_collect() walks every RRset in the response, including the CNAME chain, and skips records it has already seen.

Sort & choose

Records are ordered CNAME, A, AAAA, MX, PTR. The main IP is the first A record, or the first AAAA if there is no A. record_used says whether an alias was followed.

Why ask for MX at all? An MX answer doesn't change the main IP, but it's still collected and shown. Some names (like mail-only domains) have MX records and no address. In that case the lookup is FAILED with “No IP address (A/AAAA) record found”, while records still lists the MX entries.

last_error = None
for qtype in ("A", "AAAA", "MX"):
    try:
        _collect(res.resolve(target, qtype), records)
    except dns.resolver.NoAnswer:
        continue
    except dns.resolver.NXDOMAIN:
        return _result(target, error=f"'{target}' does not exist (NXDOMAIN).")
    except dns.resolver.NoNameservers:
        last_error = "No DNS server could answer the query."
    except dns.exception.Timeout:
        last_error = "DNS query timed out."
    except dns.exception.DNSException as e:
        last_error = f"DNS error: {e}"

records.sort(key=lambda r: TYPE_ORDER.index(r["type"]) if r["type"] in TYPE_ORDER else 99)

addresses = [r["value"] for r in records if r["type"] in ("A", "AAAA")]
if not addresses:
    return _result(target, records=records,
                   error=last_error or f"No IP address (A/AAAA) record found for '{target}'.")

main_ip = next((r["value"] for r in records if r["type"] == "A"), addresses[0])
return _result(target, ip=main_ip, hostname=target, records=records)
