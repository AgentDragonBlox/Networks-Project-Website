Interactive demo / Python network toolkit

Watch a network diagnosis happen, one module at a time.

The Network Diagnostics and Path Analysis Tool resolves a name, measures round-trip time, traces each router on the path and then points out where the path is slow or losing packets. Each module has its own page with a live lab that runs the project's logic step by step, from validation and regex parsing to statistics and the exact terminal output.

DNS runs first. Its main IP is passed to ping and traceroute, and the traceroute hops go to path analysis, the same flow the project uses: run_traceroute(result.ip) → analyze_path(result).

What's real and what's simulated. DNS lookups are real when Live mode is on: they're sent to Cloudflare over DNS-over-HTTPS. Browsers can't send ICMP packets, so ping and traceroute use a simulated network that produces the same text ping, tracert and traceroute print. Everything after that, the validation, regexes, parsing, statistics, bottleneck rules and printed reports, is a faithful JavaScript port of the Python code.
